## Reflection

Laboratory Activity 10 allowed me to combine the concepts and skills
that I learned throughout the previous Cloud Computing laboratory
activities.

For this final mission, I designed and deployed a multi-tier
application using Ubuntu Server, Docker, Docker Compose, WordPress,
and MySQL.

I learned how to organize an application into separate application
and database tiers and how Docker containers communicate through a
private Docker network.

Persistent Docker volumes were configured so that application and
database data could remain available even after containers or the
virtual machine were restarted.

Security was implemented using UFW. I configured a default-deny
incoming policy and allowed only the ports required for SSH and web
application access.

I also created a Bash automation script for database backups and
configured Cron to execute the script automatically.

This activity helped me understand that cloud infrastructure requires
more than deploying an application. It also requires architecture,
security, storage, automation, monitoring, maintenance, and
documentation.

The project brought together the concepts learned from the earlier
laboratory activities and provided practical experience in building
and managing a complete cloud infrastructure.

Overall, Mission 10 improved my understanding of Linux administration,
containerization, infrastructure as code, security, persistent
storage, automation, and cloud system operations.
